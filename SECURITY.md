# Security policy

## Supported versions

Security fixes go into the latest release of os-optics-kit on PyPI. Upgrade with
`python -m pip install --upgrade os-optics-kit`.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: on the repository's **Security** tab choose
**Report a vulnerability** ([direct link](https://github.com/JunLin615/os-optics-kit/security/advisories/new)).
Do not open a public issue for a vulnerability.

Include the affected version, the steps or input that trigger the problem, and what an attacker could do with it.
You will get a reply on the advisory, and the fix and its release are coordinated there.

This policy covers the code, workflows and packaged data of this repository. Vulnerabilities in the os-optics
engine belong to the [os-optics repository](https://github.com/JunLin615/os-optics); report them there in the same
private way.
